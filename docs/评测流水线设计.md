# 评测流水线设计（衡评 EvalPipe）

> 2026-11-23 · v0.1。目标：把"跑分"变成"可归因、可复现、可回流、可门禁"的质量工程。
> 适用对象：Coding Agent（Codex/Claude Code/Qoder/自研）与业务 Agent（HengERP）共用同一方法论。

## 二、我的系统性补充（图片之外，但决定流水线是否可信）

1. **归因先于指标**。没有归因的通过率是误导：题坏拉低分数会被误读为模型差。因此 oracle 参考解先验证"题目/单测本身有效"（归因第 2 步），探针套件作为归因链路的金丝雀（每次运行必须 3/3 验证）。
2. **双轨断言**。代码/财务结果只用确定性断言（pytest/精确表达式）；LLM-as-judge 只评过程质量（指令歧义、解释完整性），且必须校准（见 M2）。禁止用 judge 给"对错"打分。
3. **环境钉死与复现**。每任务 git 基线 commit + requirements 探针 + 超时控制 + 自动复现脚本；容器模式断网（--network=none）防"网络依赖型假失败"。
4. **防应试（Goodhart）**。轮换保留集（rotate --seed）对候选生成器不可见；judge 与生产模型异源；探针失败不计入模型分但计入"归因链路健康度"。
5. **统计门禁**。门禁不看总通过率一个数：eps 容差 + 逐任务回归检测（基线通过→现在模型类失败）+ 新增题坏强制先修数据集；探针豁免。flaky 策略：重试一次仍失败才记失败并标 flaky（M2 完善）。
6. **成本与时延是一等指标**。tokens/cost/avg_duration 进报告与门禁（成本暴涨=路由或 prompt 回归）。
7. **版本化**。套件 YAML 即数据集版本；run manifest 记录 adapter/seed/split/docker；基线 JSON 钉住比较对象。
8. **回流闭环**。模型类 badcase → 回归集新增 + HengERP 进化中心案例池（eval_backflow source），题坏 → 数据集修订清单，环境 → 环境修复清单；三条路由都有产物文件，可被 CI/人消费。

## 三、固定顺序归因（排查纪律）

拿到失败样本，按序排查，**命中即停**并留证据：
1. 指令是否模糊/矛盾（探针标签或 judge 判定）→ 题坏/指令
2. 单测或预期答案是否有错（oracle 也失败）→ 题坏/测试
3. 依赖/版本/网络/容器（env 探针）→ 环境
4. Agent 规划 / 工具调用(patch apply) / 幻觉(不存在符号) / 逻辑(单测未过) → 模型
5. 多轮上下文截断 / prompt 缺陷（transcript 标记）→ 上下文

## 五、与 HengERP 的关系

- HengERP 自带 17 个黄金评测（业务断言）；本流水线提供**方法论外壳**：归因/回流/门禁/看板/M2 钩子。
- 桥接：模型类 badcase 导出 `heng_evolution_export.jsonl`（source=eval_backflow），可注入 HengERP 进化中心案例池；反向可把 heng_eval 的 JSON 报告归一化进本看板（M2 适配器）。
- 两边共用纪律：确定性断言一票否决、judge 只评过程、进化/发布必须过门禁。

## 六、开源 bench 数据格式对照（读仓库笔记）

| 来源 | 关键格式 | 本规格对应 |
|---|---|---|
| SWE-bench | instance_id, repo, base_commit, patch( gold ), test_patch, FAIL_TO_PASS/PASS_TO_PASS | id / files(=base 快照) / oracle_files(=gold) / tests(=test_patch) / 单测前后对比=M2 |
| Aider polyglot | 每语言 exercises 目录 + 独立测试文件 + 指令 md | suite 目录 + tasks/*.yaml + tests 内嵌 |
| HumanEval | prompt + canonical_solution + test | instruction + oracle_files + tests |
| Cursor benchmark | 私有任务但公开方法论：编辑级任务+测试裁决 | kind=bugfix + patch 捕获 |

## 七、诚实边界

- mini-bench 为自建子集，**分数不代表官方 HumanEval/SWE-bench 成绩**；用于练归因与门禁链路。
- CLIAdapter（Codex/Claude Code/Qoder）协议已实现但本环境未实跑；LLM 适配器需配置密钥；Docker 视环境启用。
- 当前隔离为进程级+git 基线；容器级隔离在具备 Docker 的环境一键切换。
